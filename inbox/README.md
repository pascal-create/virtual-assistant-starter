# Inbox (the mail slot)

Drop anything here. Grok and other AIs write here too, and only here. Claude is the only one who files things into the rest of the brain.

To file everything, say "process my inbox" in Claude Code. If the night shift is on (`references/nightly-routine.md`), it also happens every night.

| Folder | What goes in it |
|---|---|
| `emails/` | Emails that matter, ones you wrote or received. Paste them into a text file, or save them as PDF. |
| `transcripts/` | Meeting and call transcripts, talks, videos where you speak. |
| `voice-memos/` | The text of a voice memo or a brain dump. Drop the text, not the audio file. |
| `ai-chats/` | Good ChatGPT, Claude or Grok conversations, and Grok's "send to brain" notes. |
| `other/` | Anything else: documents about you or your business, notes, posts you wrote, Grok's sync files. |
| `_processed/` | Where filed items go, with the date in front. Nothing is ever deleted. |

**Rules for every AI that writes here**
- Plain `.md` files, not Google Docs. Name them `YYYY-MM-DD-HHMM-short-topic.md`.
- Use the format in `templates/send-to-brain.md`.
- Save into the subfolder that already exists. Never create a folder. Never touch anything outside `inbox/`.

**Never put here:** passwords, card or bank numbers, government ID numbers.
