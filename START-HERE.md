# Start here

**What this is.** A folder in your Google Drive that holds everything your AI needs to know about you and your business.
Claude Code (in VS Code) fills it, files into it and keeps it tidy. Your Grok Chief of Staff reads it from your phone.
You talk, they remember. You stop re-explaining your business to every AI.

## The 5 phrases

| Say this | Where | What happens |
|---|---|---|
| "set up my brain" | Claude Code | The setup interview starts: about 20 short questions, one at a time. |
| "continue my setup" | Claude Code | The interview picks up where it stopped (new chat, closed laptop, anything). |
| "I'm done" or "ingest that" | Claude Code | Claude files what happened in this chat into the brain. Say it at the end of every chat. |
| "process my inbox" | Claude Code | Claude files everything waiting in `inbox/`: Grok notes, documents, transcripts. |
| "send to brain" | Grok | Grok saves a note in `inbox/`. Claude files it later. |

## 3 rules

1. **Never move or rename this folder.** Claude's memory, the night shift and Grok all find it by its name and place.
2. **One Google account everywhere.** The same one for Google Drive, Claude's connectors and Grok.
3. **Grok writes only to `inbox/`.** Claude is the only one who files things into the rest of the folder.

## Where things live

| Folder or file | What's in it |
|---|---|
| `index.md` | The map of everything. Start here. |
| `context/` | About you: profile, priorities, goals, how you write, your customers. |
| `people/` | One page per person. |
| `companies/` | One page per client, supplier or partner. |
| `meetings/` | One page per meeting. |
| `daily/` | One note per day, written by Claude. |
| `decisions/` | Every decision, one line each. |
| `inbox/` | The mail slot. Drop anything here. |
| `projects/` | One folder per project. |
| `references/` | Price lists, how-tos, your AI team, the night shift setup. |
| `grok/` | Your Grok instructions and prompts. |
| `archives/` | Old material. Nothing is ever deleted. |

## If something goes wrong

| If this happens | Do this |
|---|---|
| Claude doesn't seem to know you | Start a new chat (the + at the top of the Claude panel). Claude reads your files at the start of each chat. |
| The setup stopped halfway | Open a new chat and say "continue my setup". Nothing is lost. |
| VS Code shows a "Restricted Mode" bar | Click Manage, then Trust. |
| Claude Code asked "Trust this folder in Claude Code?" and you clicked Don't trust | Command Palette (Cmd/Ctrl+Shift+P) > Developer: Reload Window. It asks again: click Trust folder. |
| You're typing in a panel called Chat | That's Microsoft's assistant, not Claude. Click the orange spark icon and use the Claude Code tab. |
| Gmail or Calendar don't work in Claude Code | Connect them in the Claude desktop app (Customize > Connectors) with the same Google account, then start a new chat. A green check means connected. |
| Folders like "people (1)" show up in Drive | Say "process my inbox". Claude merges them. Then remind Grok: inbox only, never create folders. |

**Never put in this folder:** passwords, full card or bank numbers, government ID numbers, or client health or legal records.
